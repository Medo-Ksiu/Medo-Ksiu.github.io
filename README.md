# البورتفوليو بتاعك

موقع ستاتيك (HTML + CSS + JavaScript) من غير أي build أو مكتبات. افتح `index.html` في المتصفح وهيشتغل على طول.

## الملفات

```
portfolio/
├── index.html        ← هيكل الصفحة (مش محتاج تلمسه)
├── css/style.css     ← الألوان والتصميم (الألوان كلها في أول الملف)
├── css/fx.css        ← الأنيميشن
├── js/data.js        ← ★ كل المحتوى هنا: بياناتك، مهاراتك، خبراتك، ومشاريعك
├── js/main.js        ← المنطق (فلترة، بحث، ثيم، لغة، Ctrl K)
├── js/fx.js          ← التأثيرات والتيرمنال
└── assets/projects/  ← حط هنا صور مشاريعك
```

## إزاي تضيف مشروع

افتح `js/data.js`، وفي `projects` انسخ أي مشروع وعدّل:

```js
{
  id: "my-app",                 // اسم فريد بالإنجليزي من غير مسافات
  file: "App.tsx",              // اسم الملف اللي بيظهر على الغلاف
  title:   { en: "My App", ar: "تطبيقي" },
  summary: { en: "One line…",   ar: "سطر واحد…" },
  details: { en: ["Point 1", "Point 2"], ar: ["نقطة 1", "نقطة 2"] },
  category: "web",              // web | landing | backend | mobile (أو ضيف تصنيف في categories)
  stack: ["React", "Node.js"],
  year: "2026",
  links: { live: "https://...", code: "https://github.com/..." },
  color: "#4F7F8A",             // لون الغلاف
  image: "",                    // أو "assets/projects/my-app.png"
  featured: false,              // true = كارت كبير بعرض الصف
  sample: false
}
```

لو عايز تخفي مشروع، امسحه من القايمة. ولو عايز تحط صورة، حطها في `assets/projects` واكتب مسارها في `image`.

## مميزات جوه الموقع

- عربي / إنجليزي بزرار واحد (والاتجاه بيتقلب RTL تلقائياً)
- ثيم فاتح وغامق، وبيفتكر اختيار الزائر
- فلترة المشاريع حسب التصنيف + بحث بالاسم أو التقنية
- `Ctrl K` أو `/` لقائمة أوامر سريعة (تنقل، فتح مشروع، تغيير الثيم، نسخ الإيميل)
- ساعة بتوقيت القاهرة، وشريط تقدم القراءة فوق
- شاشة بداية على شكل تيرمنال (بتظهر مرة واحدة في كل زيارة، وأي زرار يتخطاها)
- اسمك بيطلع كلمة كلمة، وتحته أدوار بتتكتب وتتمسح لوحدها (`typedRoles` في data.js)
- كارت الكود بيكتب نفسه سطر سطر
- خلفية نقط بتتفاعل مع الماوس وبتعمل شبكة حوالين المؤشر
- أرقام بتعد لفوق (`stats` في data.js)، وشريط تقنيات بيلف
- كروت المشاريع بتميل مع الماوس وعليها إضاءة بتمشي ورا المؤشر
- العناوين بتتفك كأنها كود، والتايم لاين بيترسم وانت نازل
- تيرمنال حقيقي الزائر يكتب فيه أوامر: help, projects, open 1, skills, contact, sudo hire-me
- كل الحركات بتقف لوحدها لو الزائر مفعّل "تقليل الحركة"
- يحترم إعداد "تقليل الحركة" عند الزائر

## النشر مجاناً

**GitHub Pages:** ارفع الفولدر في ريبو اسمه `username.github.io` → هيبقى الموقع على `https://username.github.io`.

**Netlify:** ادخل app.netlify.com/drop واسحب الفولدر كله جوه الصفحة.

**Vercel:** `npx vercel` من جوه الفولدر.
